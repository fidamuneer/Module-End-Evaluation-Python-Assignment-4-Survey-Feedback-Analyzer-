# Survey Feedback Analyzer

**Project Name:** Survey Feedback Analyzer  

## About the Project

This project created to practise Python fundamentals. The program collects customer feedback, stores the details, cleans the feedback text, and finds useful information from the collected data.
The customer details are stored using a dictionary with lists.

## What This Project Does

- Stores customer names, feedback, ratings, and serial numbers.
- Allows users to enter new customer feedback.
- Automatically generates serial numbers for new entries.
- Cleans feedback by removing punctuation and unnecessary spaces.
- Converts all feedback text into lowercase.
- Counts feedback entries containing words like `good`, `poor`, and `excellent`.
- Finds the feedback with the highest number of words.

## Python Concepts Practised

While completing this assignment, I practised:

- Variables and data types
- Lists and dictionaries
- For loops and if conditions
- Functions and parameters
- String methods such as `replace()`, `split()`, `join()`, and `lower()`
- List methods such as `append()`
- Built-in functions such as `len()`

## How to Run the Project

1. Install Python on your system.
2. Download this repository.
3. Open the Python file using IDLE or any Python editor.
4. Run the program.
5. Enter the number of feedback entries you want to add.
6. Provide the customer details, feedback, and rating when prompted.

## Sample Data

The program starts with 10 sample customer feedback entries. You can also add new feedback entries while running the program.
